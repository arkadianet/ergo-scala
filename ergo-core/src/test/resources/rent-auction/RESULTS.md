# Rent-auction verification

The current results are in [VERIFICATION.md](../../../../../docs/rent-auction/VERIFICATION.md),
with a generated [machine-readable report](../../../../../docs/rent-auction/verification.json).

wallet signing support, persistent UTXO/digest tests, Python operator tests and a
compiled/tested Lithos adapter. It is a draft for review, not an activated network
protocol or an independent security audit.
